FFmpeg 8.0.3 与 LAME 3.100

本目录的 ffmpeg/ffprobe 为独立命令行工具，仅由 ToMP3 通过子进程调用，按平台各一份：
macOS arm64（Mach-O）与 Windows x64（PE32+，文件名带 .exe）。两个平台由同一份源码、
同一段解码器筛选逻辑构建，见 build.sh 的 mac / win 分支。
FFmpeg 和 libmp3lame 静态链接：macOS 版动态依赖仅来自系统库（libz 来自系统），
Windows 版动态依赖仅来自系统 DLL（zlib 随包源码静态编入）。运行不需要 Homebrew、额外 FFmpeg 或网络。
macOS 部署目标为 12.0。未启用 GPL 或 nonfree 组件。

三份源码均未修改，构建参数完整保留在 build.sh。重建：
  bash src/ToMP3/Assets/ffmpeg/build.sh /绝对路径/artifacts/ffmpeg-build       # macOS arm64，需要 Xcode 工具
  bash src/ToMP3/Assets/ffmpeg/build.sh /绝对路径/artifacts/ffmpeg-build win   # Windows x64，需要 mingw-w64 与 nasm
脚本将从随附源码重建并替换当前目录对应平台的工具。可修改源码及相应校验值，重建使用修改版本。
运行 ToMP3 不需要这些构建工具；构建脚本和源码仅用于许可履行与复现。
